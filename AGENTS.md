# Contributor guidance

- Read README.md and the affected guide under docs/ before changing behavior.
- Keep company examples here and reusable runtime behavior in Dispatch's runner.
- Use synthetic data. Never commit credentials, local state or private logs.
- Run npm run check, inspect the diff and exercise the documented demo after
  relevant changes. Record actual observations and remaining gaps.
- Keep both skill scopes useful, and preserve explicit definition updates and
  saved conversations. See docs/authoring.md and docs/operations.md.
- Follow CONTRIBUTING.md for publication and review requirements.
