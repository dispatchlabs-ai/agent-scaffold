# Company code

Put company-specific tools, integrations and startup code here when you need
execution. Choose the language and runtime that fit your agents, then document
their setup and required access in `docs/`.

Keep each agent's instructions and its own skills in its `agents/` folder,
with shared guidance in `skills/`. This directory starts with no executable code
or dependencies. The optional [Dispatch example](../examples/dispatch/README.md)
shows one complete implementation, including its own `src/`.
